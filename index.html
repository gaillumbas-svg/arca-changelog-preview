Week 1 Day 2: New Resume Lesson Added

New lesson
Before

Day 2's welcome module did not include the resume/Markdown-file exercise.

After + Draft

A new no-video, no-exercise page was added at week-1/day-2-front-end-design/welcome-to-day-2/introduction-to-md-files.md.

Release note

The new lesson teaches students to use a provided .md instructions file as a reusable recipe for upgrading resumes with Claude. It includes a sample messy resume and an ATS resume-upgrade instruction file as attachments, asks students to practice on the sample first, then apply the process to their own resume.

Content areaWhat changed
New conceptIntroduces .md files as plain-text instruction recipes students can give to Claude.
New activityStudents practice on a sample resume, compare before/after bullets, then run the same workflow on their real resume.
Output expectationStudents fill placeholders with real numbers, export a Word document, and post their best before/after bullet.
